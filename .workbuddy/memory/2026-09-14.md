## 调研：Reborn XP 素材/功能移植可行性（产出方案文档）

用户想把爬取的 `~/Downloads/xp.quenq.com`（**Reborn XP，闭源**）移植进本项目做中文版。

**产出**：`docs/RebornXP-移植方案.md`（完整方案，含素材对照表、16 个应用实施清单、开发模板、P0–P5 路线图、风险边界）。

**关键调研结论（复用价值高，别再重查）**：

1. **两侧图标同源**：本项目 `src/assets/fileIcons/` 69 个里，41 个与对方 `res/icons/` 同名，抽查 6 个 md5 完全一致。只缺 15 个：
   `calc diskclean empty font gif gonnacry imgviewer mines repl sndvol solitaire spider theme winupdate wordpad`，
   外加对方独有的 `res/icons/start/`(8) 与 `res/icons/tray/`(55) 两套小图标。
2. **开始菜单已备好**：`src/WinXP/Footer/FooterMenuData.js` 已有 57 条中文菜单项（含纸牌、3D弹球、WMP、录音机、音量控制、MSN、Outlook Express 等），图标也 import 好了，**只是无后端组件，点击落进 ErrorBox**。缺的是组件，不是 UI。
3. **音效无需移植**：本项目 8 个 > 对方 3 个。
4. **字体有法律雷**：对方 `res/fonts/Tahoma.ttf` 名称表 = `© 2004 Microsoft Corporation`，**不可分发**；
   `MSSansSerif 8pt.ttf` / `Tahoma 8pt 11-2.ttf` 是爱好者重制（署名 Anonymous / MicrosoftKonsti），授权不明；
   `Web437_IBM_VGA_8x14.woff` = VileR Oldschool PC Font Pack，**CC BY-SA 4.0 可自由用**。
5. **对方原生 JS + 全局 window.shell 架构**，`shell.js` 33 个方法；与本项目 React+reducer 完全不同 → 代码不可搬，只做规格参考。
6. **本项目现存问题（顺手可修）**：
   - 桌面壁纸是**外链** `https://blog.sdcom.top/upload/Zk6TR5k.jpg` → 应换本地 `Bliss.jpg`
   - `font.css` 引的是 **Noto Sans TC（繁体）** → 应换 `Noto Sans SC`
   - VFS 是**只读 JSON**，没写入/持久化 → 记事本存不了盘、右键"新建"是灰的
   - 任务栏时钟是 **12 小时 AM/PM 制** → 中文 Windows 应为 24 小时
   - 托盘图标是假的（690/394/229 三个固定 png）

**新增应用开发模板（6 步）**：建 `src/WinXP/apps/<Name>/` → 写 `index.js`（收 `{onClose, injectProps}`）+ `dropDownData.js` → 在 `apps/index.js` 注册（`defaultIconState` + `appSettings` + export）→ 在 `WinXP/index.js` 的 `onClickMenuItem` 加 if 分支（**菜单 text 必须与 FooterMenuData.js 完全一致**）。
图标丢进 `assets/fileIcons/` 会被 `require.context` 自动 glob，无需改代码。
