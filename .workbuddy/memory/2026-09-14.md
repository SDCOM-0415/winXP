4. **字体有法律雷**：对方 `res/fonts/Tahoma.ttf` 名称表 = `© 2004 Microsoft Corporation`，**不可分发**；
   `MSSansSerif 8pt.ttf` / `Tahoma 8pt 11-2.ttf` 是爱好者重制（署名 Anonymous / MicrosoftKonsti），授权不明；

6. **本项目现存问题（顺手可修）**：
   - 桌面壁纸是**外链** `https://blog.sdcom.top/upload/Zk6TR5k.jpg` → 应换本地 `Bliss.jpg`
   - `font.css` 引的是 **Noto Sans TC（繁体）** → 应换 `Noto Sans SC`
   - VFS 是**只读 JSON**，没写入/持久化 → 记事本存不了盘、右键"新建"是灰的
   - 任务栏时钟是 **12 小时 AM/PM 制** → 中文 Windows 应为 24 小时
   - 托盘图标是假的（690/394/229 三个固定 png）

### 重大发现：基准站无法作为可交互参照物
1. `xp.quenq.com` 顶层打开时会被 index.html 的内联脚本**重定向**到 `quenq.com/apps/reborn-xp`；
   只有 host 为 localhost/127.0.0.1 或处于 iframe 内才不跳转
2. **爬下来的那份跑不起来**：本地起静态服务后 `window.shell` 是 `undefined`，
   `js/shell.js`、`js/DiskManager.js`、`js/explorer.js` 这几个 ESM 模块根本没被加载
   （index.js 以模块方式 import 它们），实际只加载了 wm.js / themehandler.js /
   dialoghandler.js / apps.js / screensave.js。即**这份爬取是"外壳"，缺运行所需环节**
3. 真实模拟器只存在于 `quenq.com/apps/reborn-xp` 页面的**跨域 iframe**（`#app-iframe` → `https://xp.quenq.com/`）里，
   脚本无法注入，且它会停在自家的 OOBE 引导页（"Welcome to Microsoft Windows"），驱动不到桌面

**结论**：无法用"截两张图做像素比对"的方式做逐项对齐。
可行办法是**把它的 CSS/HTML/JS 当规格书**（19MB 可读），逐面提取精确色值/尺寸再在自研代码里实现。
其 CSS 用的是自定义元素命名（`taskbar` / `startbtn` / `trayarea`，无点号前缀），
关键文件：`css/luna/blue.css`、`css/luna/controls.css`、`css/classic/modules.css`、
`css/applayouts.css`(55KB)、`css/scenes.css`、`css/colors.css`。

### 验证手段（本轮学到，很有用）
网页自动化的关键技术点：
- `agent-browser eval "<js>"` 可以读取**运行时真实计算样式**，比看截图准得多。
  用 `getComputedStyle(el).getPropertyValue('--var')` 直接验证 CSS 变量是否解析成功
- `agent-browser screenshot <path>` 可指定输出路径
- **跨域 iframe 内的内容脚本进不去**，遇到这种站点要尽早放弃界面驱动、改走规格提取
- 本地起静态服务用**受管后台任务**（`run_in_background`）才不会被回收；
  用 `nohup ... &` 在命令结束后会被杀掉
- 用 curl 探测本地端口要加 `--noproxy '*'`，否则会走代理返回 502
- **grep 的 `--xxx` 前缀会被当成命令行选项**（`grep -c -- "--taskbar-bg"` 返回 0 是假象），
  必须写成 `grep -c -e "--taskbar-bg"` 或加 `--` 分隔符。本机是 BSD grep，
  且 **BRE 不支持 `\|` 交替**，多关键词要用 `-E`
